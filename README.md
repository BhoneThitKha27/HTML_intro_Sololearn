# HTML Introduction - SoloLearn

This repo contains my full journey through the [SoloLearn HTML Introduction Course](https://www.sololearn.com/learn/courses/html-introduction), completed step-by-step with real examples and hands-on practice.

## What’s Inside

Each file in this repo corresponds to key concepts from the course, including:

- ✅ Basic HTML Structure (`html`, `head`, `body`)
- ✅ Headings and Paragraphs (`h1`–`h6`, `p`)
- ✅ Links and Images (`a`, `img`)
- ✅ Lists (`ul`, `ol`, nested `li`)
- ✅ Tables (`table`, `thead`, `tbody`, `th`, `td`, `caption`)
- ✅ Forms (`form`, `input`, `textarea`, `select`, `checkbox`, `radio`)
- ✅ Media Embeds (`audio`, `video`)
- ✅ Semantic Tags (`header`, `nav`, `main`, `section`, `article`, `footer`)
- ✅ Bonus Tags: `details`, `summary`

## About the Project

This wasn’t just a copy-paste tutorial run — I rebuilt everything manually, tested each tag, and made real examples to understand how HTML actually works.  
**The goal** was to master the foundation before moving into CSS.
